# EmoVision

Proyek EmoVision adalah platform kesehatan mental digital interaktif berbasis web yang dirancang sebagai ruang aman (safe space) bagi pengguna untuk mengenali, melacak, dan mengelola kondisi emosional mereka secara mandiri. Berbeda dengan aplikasi jurnal konvensional yang cenderung pasif dan searah, EmoVision hadir dengan pendekatan Multimodal yang responsif. Aplikasi ini mengombinasikan analisis teks berbasis Natural Language Processing (NLP) dan deteksi ekspresi wajah berbasis Computer Vision untuk memvalidasi perasaan pengguna secara objektif dan real-time.

## Tech Stack
Proyek ini dibangun menggunakan teknologi berikut:
- **Python**: Bahasa pemrograman utama untuk pengolahan dan analisis data.
- **Google Colab**: Tools pengembangan berbasis *cloud* untuk kolaborasi dan pengolahan data.
- **Kaggle**: Sumber dataset sekunder untuk riset dan pengembangan model.

## Struktur Proyek
- `Final Dataset Gambar`: Dataset yang digunakan untuk analisis.
- `DATASET_GAMBAR_FINAL.ipynb` : Notebook analisis dataset gambar citra wajah

## Fitur Utama
- **Data Collection**: Mengumpulkan dataset gambar, mengelompokkan data ke dalam tujuh kategori emosi yaitu Happy, Sad, Neutral, Disgust, Surprise, Angry, dan Fear, serta menyusun struktur folder dataset sesuai kategori untuk memudahkan pengelolaan data. 
- **Data Cleaning** : Melakukan pemeriksaan gambar rusak, peningkatan kualitas citra, serta standardisasi ukuran gambar untuk menghasilkan dataset yang lebih konsisten dan siap digunakan.
